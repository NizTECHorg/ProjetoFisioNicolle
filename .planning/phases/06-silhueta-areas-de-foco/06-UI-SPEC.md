# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase goal:** No Resumo da ficha, o card **Áreas de foco** deixa de ser o boneco palito e vira uma silhueta humana simples (frente e costas). Hover 500 ms (ponteiro fino) abre uma abinha; clicar a abinha marca ou desmarca a região. Persistido em `patient_focus_areas`. Quem não pode escrever só vê.

**Sources:** tokens from `src/index.css`; card chrome from `PatientPage.tsx` Resumo; analog panel `PatientGoalsPanel` (hide when `!canWrite`); product from `06-CONTEXT.md` (D-01–D-10) and `06-RESEARCH.md`; spacing / type / color reused from `03-UI-SPEC.md` (approved) and `05-UI-SPEC.md`. Catalog trimmed from RESEARCH A4 (merge mão→braço, pé→perna, nuca→cervical). Layout reference: `refs/referencia-silhueta-frente-costas.png` (frente+costas + regiões) — **do not** copy navy `#0A1651`, orange `#FF7D16`, musculature, Male/Female, or widget chrome.

**Do not restyle** `Button`, `Input`, `Select`, `Modal`, `PageHeader`, `ConfirmDialog`, `DataTable`, `Badge`, `ToastViewport`, or AppShell. Do **not** add shadcn, Radix Tooltip, Floating UI, `clsx`, or a third-party body-map widget (D-02).

## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|

| sm | 8px | Gap between a figure and its **Frente** / **Costas** caption |
| md | 16px | Gap between the two silhouettes; empty-copy top margin (`mt-4`) |
| lg | 24px | Unused this phase (card stays `p-4`) |
| xl | 32px | Unused this phase |
| 2xl | 48px | Unused this phase |

Exceptions:

- Card chrome stays `rounded-2xl border border-line p-4` and title `mt` to figures stays **12px** (`mt-3`) — match the current Áreas de foco card; do not restyle padding to 16px.

- Existing `Button` / `Input` padding is unused on this card. Do not introduce a `Button` primary in the card header.

## Typography

Exactly four sizes and two weights for **new** copy in this phase (same contract as Phase 3 / Phase 5):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px (`text-sm`) | 400 | 1.5 |
| Body | 14px (`text-sm`) | 400 | 1.5 |
| Heading | 20px (`text-xl`) | 600 | 1.2 |

Display is **unused** this phase — do not invent a fifth size for the card. Empty copy, chip visible text, and **Frente** / **Costas** captions use **Body 14px / 400**. Chip action that is pressed uses **14px / 600** (the second declared weight), not a new size.

Do not introduce `text-xs` (12px) on this card. Existing muted meta on other Resumo cards stays as-is.

Existing chrome exceptions (do not restyle):

- Card title **Áreas de foco** remains `text-[11px] font-semibold uppercase tracking-[0.14em] text-accent`.
- Toast copy stays at the existing `ToastViewport` size.

## Copywriting Contract

All user-facing strings in Portuguese (pt-BR). Technical keys (`region_key`) stay English dotted ids. No generic Submit / OK / Save / Cancel. No native `title` tooltip copy.

| Element | Copy |
|---------|------|
| Primary CTA | **Marcar {região}** (visible label of the abinha when the region is unmarked). Pressed: **Desmarcar {região}**. |
| Empty state heading | Sem áreas registradas. |
| Empty state body | Passe o cursor 0,5 s sobre uma parte e clique na abinha para marcar. No toque, toque na parte e depois na abinha. |
| Error state | Não foi possível salvar a área. Tente de novo em instantes. |
| Destructive confirmation | none — desmarcar is an immediate toggle (INSERT/DELETE). Do not open `ConfirmDialog`. |

Empty body is shown **only** when `canWrite` and there are zero keyed rows. When `!canWrite` and empty, show **only** the heading **Sem áreas registradas.** — do not instruct a consult-only viewer to mark.

| Figure caption right | Costas |

### Abinha (chip)

Visible text is the CTA, not the bare anatomy name alone.

| State | Visible label | `aria-pressed` |
|-------|---------------|----------------|
| Unmarked, writable | Marcar {label} | `false` |
| Marked, writable | Desmarcar {label} | `true` |
| `!canWrite` | Chip **unmounted** — no disabled-looking control | n/a |
| `isPending` | Keep the same label; `aria-busy="true"` | unchanged until invalidate |

`{label}` is the Portuguese catalog label (table below), e.g. **Marcar Ombro esquerdo**. Front and back may share a label; the chip is anchored on the figure, so do not append “(frente)” on the visible chip. Screen-reader list of marked areas **does** append the view: `{label} (frente)` / `{label} (costas)`.

## Screens

### 1. Resumo — card Áreas de foco

- Lives in `ResumoDoPaciente` on `PatientPage`. Same grid cell (`lg:col-span-1`). No new tab, route, or dashboard widget (D-02).
- Replace the inner `flex` + `BodyFocus` + `<ul>` with `<PatientFocusAreasPanel patientId={...} focusAreas={detail.focusAreas} canWrite={canWrite} />`.
- Keep the outer card: `rounded-2xl border border-line p-4` + title **Áreas de foco**.
- Delete `function BodyFocus()` and the hardcoded accent circles (`cy={132}` / `cy={108}`).
- Delete the visible side list (D-01). Do **not** bring it back at `xl`. Silhouette is the source of truth.
- Mount a visually-hidden `<ul className="sr-only">` of marked labels (`{label} (frente|costas)`) when `focusAreas.length > 0`. When empty, do not output a hidden list.

### 2. Pair of silhouettes

- Two inline SVGs **side by side**, `flex items-end justify-center gap-4`, each `flex flex-col items-center`.
- Genderless adult outline — one artwork for every patient. No Male/Female control (D-04 / deferred).
- Simple filled regions + a non-interactive outline layer (`pointerEvents="none"`, `fill="none"`, `stroke="currentColor"`). No muscle striations, no 3D, no photo.
- Regions: closed, **non-overlapping** `<path>`s with `pointerEvents="fill"` and a real fill (never `fill="none"`). Visual gap **4px** (xs token) between adjacent paths; do not overlap hit targets. Stroke widths 1.5 / 1.2 are drawing, not spacing.
- `viewBox` per figure approximately `0 0 140 240`. `className="h-44 w-auto text-forest sm:h-52"`.
- Caption under each: **Frente** / **Costas** at Body 14px / 400 / `text-muted` / `mt-2`.
- Each focusable path (`tabIndex={0}` when `canWrite`) has `aria-label` from the catalog (see Copywriting). The figure `aria-label` is not enough.
- Highlight = persisted `region_key` in `focusAreas`. Rows with `region_key === null` are ignored (no fake dots).

### 3. Abinha (chip)

- HTML `<button type="button">` inside the **same** wrapper as the active path (one pointer group). Not a native `title`. Not `Modal`. Not a portal.
- Position: adjacent to the region’s `getBBox()` (SVG user units mapped to the wrapper), overlapping the path by ≥4px so pointer travel does not fire `pointerleave`.
- Chrome: `min-h-11 min-w-11 rounded-lg border border-line bg-surface px-3 text-sm text-ink shadow-[0_8px_24px_rgba(11,29,54,0.10)]`. Pressed (already marked): `border-accent bg-accent-soft`.
- Only one chip open at a time.
- `canWrite === false`: do not render the button, do not set `tabIndex` on paths, `cursor-default` on the SVG. Saved fills still show.

### 4. Empty and error

- Empty: both silhouettes remain (no highlights) + copy under the pair, centered, `mt-4 text-sm text-muted`. Heading and optional body as in the copy table. Do **not** replace the map with an icon well.
- Toggle error: existing `toast()` error tone. Do not add an in-card error article (the ficha already has a page-level load error).

## Interaction Contract

Constant: `HOVER_OPEN_MS = 500`. Gate delayed open on `window.matchMedia('(hover: hover) and (pointer: fine)').matches`.

| Action | Behavior |
|--------|----------|
| Fine pointer enters a region (`canWrite`) | Start 500 ms timer. Do **not** open immediately. Do **not** write. |
| Fine pointer stays 500 ms | Open chip for that `region_key`. Preview fill (accent/20) if unmarked. |
| Pointer moves from path onto chip | Chip stays open (same group). No close timer. |
| Pointer leaves region+chip | Clear timer; close chip; drop preview fill. Marked fill stays. |
| Click / tap **path only** | Never INSERT/DELETE (D-06). Fine pointer: ignore click for write. Coarse pointer: open chip immediately. |
| Click / tap **chip** | Toggle: unmarked → mark (INSERT), marked → unmark (DELETE). Then `invalidatePatient` + toast. Close chip after success. |
| Coarse pointer / touch, tap region | Open chip immediately (skip 500 ms). Second tap must hit the chip to toggle. Tap outside closes. |
| Keyboard: Tab to region (`tabIndex={0}` when `canWrite`) | Open chip immediately (no 500 ms). |
| Escape | Close chip; return focus to the region path. WCAG 1.4.13 Dismissible. |
| `prefers-reduced-motion: reduce` | Skip the 500 ms delay — open on hover the same as keyboard. Do not add enter/exit animation on the chip. |
| Double-click chip | `isPending` blocks a second mutate; unique index is the server backstop. |
| `!canWrite` | No chip, no tabIndex, no pointer preview that looks tappable. Highlights of saved keys remain. |
| Empresa on colleague ficha | Same as `!canWrite`. RLS remains authority. |
| Hover flicker | Forbidden. Path+chip share one `onPointerLeave`. No CSS `:hover` as the open trigger. |

Focus ring: existing global `:focus-visible { outline-2 outline-offset-2 outline-accent }` on the path and the chip. Do not draw a second custom ring.

Reduced motion: inherit existing ficha rules; the only motion-adjacent behavior is the 500 ms **delay** (not an animation). Under `prefers-reduced-motion: reduce`, delay = 0.
