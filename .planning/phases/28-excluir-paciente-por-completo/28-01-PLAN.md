## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cliente autenticado → RPC PostgREST | `p_patient_id` vem do browser e pode ser qualquer UUID |
| Cliente autenticado → API Storage | Caminho do objeto vem do browser; RLS de `storage.objects` decide |
| Função security definer → tabelas | Roda com privilégio do dono; ignora RLS das tabelas filhas |
