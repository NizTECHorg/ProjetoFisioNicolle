uploadPatientPhoto(patientId, file, mimeType): safeParse patientPhotoSchema with byteSize file.size. On failure throw new Error(parsed.error.issues[0].message) so the user sees Envie PNG ou JPEG. or A foto deve ter no máximo 8 MB. If file.size is greater than 2 * 1024 * 1024, throw new Error('Não foi possível salvar a foto. Tente de novo.') because the bucket limit is 2097152. Extension is jpg for image/jpeg and png for image/png. Path is `${patientId}/${crypto.randomUUID()}.${extension}` with upsert false and contentType set to mimeType. Select the current photo_path for that id first. Upload the new object. Then update patients set photo_path to the new path where id = patientId. If the update fails, storage.remove the new path and throw new Error(mapDbError(error)) so 42501 stays Você não tem permissão para esta ação. Never throw error.message. If the update succeeds and the previous path is a different non-null string, storage.remove that previous path and ignore that failure. Do not insert into patient_images. Do not upload a thumbnail.

removePatientPhoto(patientId): select photo_path. If it is null, return. Update photo_path to null first. If that update fails, throw new Error(mapDbError(error)) and do not delete the object. Then storage.remove the previous path. If remove fails, throw new Error('Não foi possível remover a foto. Tente de novo.'). Other unexpected failures use Não foi possível salvar a foto. Tente de novo. Never return English Storage text.
