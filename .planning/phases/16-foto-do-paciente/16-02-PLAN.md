Create src/lib/cropPatientPhoto.ts with named export async function preparePatientPhoto(file: File). Read the first 16 bytes. Accept JPEG only when those bytes start with FF D8 FF. Accept PNG only when they start with 89 50 4E 47. Reject when the header is RIFF and bytes 8 through 11 are WEBP. Reject when the header contains the ASCII ftyp (HEIC/HEIF). If file.type is empty, also require the filename to end in .png, .jpg, or .jpeg (case insensitive). If file.type is non-empty, it must be image/png or image/jpeg and must agree with the sniffed type. Any other type, including image/webp, image/gif, image/svg+xml, application/pdf, and a renamed WebP, throws new Error('Envie PNG ou JPEG.').

If file.size is greater than 8 * 1024 * 1024, throw new Error('A foto deve ter no máximo 8 MB.') before createImageBitmap. Decode with createImageBitmap. On failure, fall back the way compressImage.ts does (object URL, Image, canvas, then createImageBitmap) but the thrown message is Não foi possível salvar a foto. Tente de novo. Never the thumbnail string Não foi possível comprimir a miniatura.

Center-crop: side = min(width, height), sx and sy center that square, draw onto a 512 by 512 canvas. Call bitmap.close(). PNG source uses canvas.toBlob with type image/png and no quality argument. JPEG source uses image/jpeg and quality 0.85. Do not call compressImageForThumb. If the blob is missing or blob.size is greater than 2 * 1024 * 1024, throw new Error('Não foi possível salvar a foto. Tente de novo.'). Return { blob, mimeType } where mimeType is image/png or image/jpeg matching the source. Do not upload. Do not import supabase.
