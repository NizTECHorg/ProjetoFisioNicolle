listPatientImages(patientId: string): SELECT IMAGE_COLUMNS from patient_images eq patient_id order created_at desc. On error throw new Error(mapDbError). Map rows. If no paths, return DTOs with signedUrl null without calling Storage. Else createSignedUrls(paths, 3600); on Storage error throw mapStorageError. Zip signed URLs by path. Empty table → [].

uploadPatientImage(patientId, file: File, input: { sessionId: string | null; description: string }): parse imageUploadSchema with mimeType file.type, byteSize file.size, sessionId, description. Generate imageId crypto.randomUUID(). Upload to IMAGE_BUCKET with contentType and upsert false. On upload error throw mapStorageError. INSERT id imageId, patient_id, session_id, storage_path, description sanitizeText(..., 500), mime_type, byte_size, session_removed false. On INSERT error: storage.remove([path]) then throw mapDbError (Pitfall 5). Return mapped row with signedUrl null (list refetch remints).

uploadPatientImages(patientId, files: File[], input): loop sequentially (D-03 same description/session for the lote). Each file is parsed; if Zod fails skip that file (D-04 — UI should have filtered, service still must not throw the whole batch on one bad MIME). On Storage/INSERT error for one file, collect the mapped message and continue. If at least one succeeded, return the PatientImage[] of successes. If none succeeded, throw new Error of the first mapped message or Não foi possível salvar. Verifique o arquivo e tente de novo.

updatePatientImage(patientId, imageId, input: UpdatePatientImageInput): UPDATE description sanitizeText 500, session_id, session_removed false (D-07: saving Editar clears Sessão removida even if still avulsa). eq id and patient_id. throw mapDbError. Return mapped row signedUrl null.

deletePatientImage(patientId, image: Pick PatientImage id | storagePath): storage.remove([storagePath]) first; on error throw mapStorageError. Then DELETE row eq id and patient_id; on error throw mapDbError and leave the object (retryable, Pitfall 5 inverse). Never SQL-delete storage.objects.

Do not import from components. Do not use getPublicUrl.
