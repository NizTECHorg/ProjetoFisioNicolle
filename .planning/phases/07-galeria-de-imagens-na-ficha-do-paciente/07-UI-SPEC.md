# Phase 7 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase goal:** Na ficha do paciente, uma quinta aba **Imagens** mostra uma galeria persistida (sem mock). Cada foto é **avulsa** ou ligada a uma sessão, com descrição. Quem não pode escrever a ficha vê a galeria e o lightbox; Adicionar imagem / Editar imagem / Excluir imagem ficam ocultos.

**Sources:** tokens from `src/index.css`; tab chrome from `PatientProfileHeader.tsx` (`overflow-hidden` pitfall); analog `PatientGoalsPanel` / `PatientEvolutionsPanel` (`canWrite` hide, Modal, ConfirmDialog); product from locked intent (no CONTEXT.md — discuss-phase skipped) and `07-RESEARCH.md`; spacing / type / color reused from `03-UI-SPEC.md` (approved) and `06-UI-SPEC.md` (latest analog).

**Do not restyle** `Button`, `Input`, `Select`, `Modal`, `PageHeader`, `ConfirmDialog`, `DataTable`, `Badge`, `ToastViewport`, or AppShell. Do **not** add shadcn, a lightbox package, Uppy, HEIC converters, or `clsx`. Do **not** hijack the Resumo shortcut **Documentos · Em breve**.

## Spacing Scale

Declared values (must be multiples of 4) — identical to Phase 3 / Phase 5 / Phase 6:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap inside filter chips and card action icons |
| sm | 8px | Gap between filter chips (`gap-2`); label-to-control on upload Modal (`space-y-2`) |
| md | 16px | Thumbnail grid gap (`gap-4`); card inner padding (`p-4`); description under thumb (`mt-2`) |
| lg | 24px | Gap between panel header and grid (`mt-6` / `space-y-6`); Modal inner padding already `p-6` |
| xl | 32px | Unused this phase |
| 2xl | 48px | Unused this phase |
| 3xl | 64px | Unused this phase |

Exceptions:

- Icon-only Modal close, card **Editar imagem** / **Excluir imagem** (`Pencil` / `Trash2` with `aria-label="Editar imagem"` and `aria-label="Excluir imagem"`), and filter chips: minimum hit area **44×44px** (`min-h-11 min-w-11`). Do not ship a 16px tap target.
- Existing `Button` padding (`px-6 py-3.5`) and `Input`/`Select`/`Textarea` (`px-4 py-3.5`) stay as implemented.
- Tablist: replace `overflow-hidden` with `overflow-x-auto` only. Keep existing `gap-5 sm:gap-6` and `py-2.5` on tab buttons. Do not change tab typography or underline thickness.
- Thumbnail tile is **square** (`aspect-square`). That ratio is the image frame, not a spacing token.

## Typography

Exactly four sizes and two weights for **new** copy in this phase (same contract as Phase 3 / Phase 5 / Phase 6):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px (`text-sm`) | 400 | 1.5 |
| Body | 14px (`text-sm`) | 400 | 1.5 |
| Heading | 20px (`text-xl`) | 600 | 1.2 |
| Display | 30px (`text-3xl`) | 600 | 1.2 |

Display is **unused** this phase — do not invent a fifth size for the gallery. Panel empty heading, filter chip text, thumbnail description, and lightbox body use **Body 14px / 400**. The selected filter chip and **Adicionar imagem** use **14px / 600** (the second declared weight), not a new size.

Hints, allocation meta (**Avulsa** / `dateLabel · timeLabel`), file helper, and toast dismiss stay at **12px** (`text-xs`) because `Input`/`Select`/`Badge`/`ToastViewport` already render that size — do not invent a fifth size; do not change those components.

Existing chrome exceptions (do not restyle):

- Ficha tab labels remain `text-sm font-medium` with forest underline when selected.
- `Modal` title remains `text-lg` / 600.
- `Input`/`Select`/`Textarea` labels remain `text-sm font-medium` (500) inside those components.
- Header / primary `Button` labels stay 14px / 600 (existing `Button` chrome).
- Patient name in `PatientProfileHeader` stays `text-2xl` / `sm:text-3xl` — out of scope.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f3f5f8` (`canvas`) | Ficha page background; thumbnail placeholder well while the signed URL loads |
| Secondary (30%) | `#ffffff` (`surface`) + `#0b1d36` (`forest`) | Gallery cards, upload/edit/lightbox Modal, primary **Adicionar imagem**; tab selected underline stays forest |
| Accent (10%) | `#2f7dff` (`accent`) | Reserved list below — never body text or primary buttons |
| Destructive | `#dc4a4a` (`error`) | **Excluir imagem** confirm (`ConfirmDialog` `tone="danger"`), inline/server errors, load-error article |

Accent reserved for:

1. **Filter chip selected** — `border-accent bg-accent-soft text-forest` on Todas / Avulsas / sessão
2. **Thumbnail whose lightbox is open** — `ring-2 ring-accent ring-offset-2`
3. Empty-state icon well on aba Imagens (`bg-accent-soft` / `text-accent`)
4. Focus ring on `Input` / `Select` / `Textarea` (`focus:border-accent` + `focus:ring-accent/25`) — already in those components
5. Success toast surface (`bg-accent-soft` + `border-success/30`) — already in `ToastViewport`

Accent is **not** for: the ficha tablist selected state (all five tabs stay `border-forest text-forest` — do not paint only **Imagens** accent), primary **Adicionar imagem** (Button stays `bg-forest`), body copy (`text-ink`), unselected chips (`border-line bg-surface text-muted`), thumbnail surfaces, or lightbox chrome.

**Focal point:** **Adicionar imagem** is the visual anchor when `canWrite`. The thumbnail grid is the supporting body. When `!canWrite`, the grid is the anchor — do not leave a disabled-looking plus button.

Do not recolor AppShell, other ficha tabs, Resumo cards, or Evoluções.

## Copywriting Contract

All user-facing strings in Portuguese (pt-BR). No generic Submit / OK / Save / Cancel on new chrome (Modal close X stays existing **Fechar** `aria-label`). No English/SQL in toasts. No native `title` tooltip as the description.

| Element | Copy |
|---------|------|
| Primary CTA | **Adicionar imagem** (`Button` primary + `Plus` 16px, panel header) |
| Empty state heading | Nenhuma imagem nesta ficha. |
| Empty state body | Toque em Adicionar imagem para enviar uma foto avulsa ou ligada a uma sessão. |
| Error state | Não foi possível carregar as imagens. Tente de novo em instantes. |
| Destructive confirmation | Excluir imagem: “A imagem será removida desta ficha.” Confirm label: **Excluir imagem**. Cancel: **Voltar**. |

Empty body is shown **only** when `canWrite` and the unfiltered list is empty. When `!canWrite` and empty, show **only** the heading **Nenhuma imagem nesta ficha.** — do not instruct a consult-only viewer to add.

### Toasts e erros de arquivo

| Event | Message | Tone |
|-------|---------|------|
| Upload success | Imagem adicionada | success |
| Edit success | Descrição atualizada | success |
| Delete success | Imagem excluída | success |
| HEIC / bad MIME | Envie JPEG, PNG ou WebP. Fotos do iPhone: escolha a opção mais compatível. | error |
| Oversize | A imagem deve ter no máximo 8 MB. | error |
| Load fail | Não foi possível carregar as imagens. Tente de novo em instantes. | in-page article, not a second toast |

| RLS / 42501 | `mapDbError` — existing “Você não tem permissão para esta ação.” | error |

## Screens

### 1. Tab **Imagens** + `?aba=imagens`

- Extend `PatientTab` with `'imagens'`. Fifth `<button role="tab">` labeled **Imagens**, after **Avaliação**.
- `PatientPage`: `aba === 'imagens'` selects the tab; `setTab('imagens')` writes `setSearchParams({ aba: 'imagens' }, { replace: true })`.
- Mount `<PatientImagesPanel patientId={dashboard.id} canWrite={canWrite} />`. Do not grow upload logic in the page.
- Tablist `nav`: change `overflow-hidden` to `overflow-x-auto`. Keep `flex items-end gap-5 … border-b border-line sm:gap-6`. Tabs stay `shrink-0`. A fifth tab must remain reachable at 375px by horizontal scroll — not clipped.
- Selected tab chrome is unchanged for all five tabs: `border-forest text-forest`. Unselected: `border-transparent text-muted hover:border-line hover:text-ink`.
- Do **not** add **Imagens** to the Resumo **Atalhos** row. Do **not** retitle **Documentos · Em breve**.

### 2. `PatientImagesPanel` chrome

- Same header pattern as Evoluções: eyebrow 12px uppercase tracking accent **Imagens**; support line 14px muted; **Adicionar imagem** on the right when `canWrite`.
- `{canWrite ? <Button>…Adicionar imagem</Button> : null}` — unmount, do not `disabled`.
- Below the header: filter chip row, then grid or empty.

### 3. Filter chips

- One horizontal row, `flex gap-2 overflow-x-auto`, chips `shrink-0 min-h-11`.
- Order: **Todas** · **Avulsas** · one chip per `usePatientSessions` row (`scheduled_at` list only — do not invent a second session query).
- Selected chip: accent reserved treatment above. Unselected: `rounded-full border border-line bg-surface px-4 text-sm text-muted`.
- Client-side filter of the already-fetched image list. Default **Todas**.
- Sessions with zero images still appear as chips (filter-empty copy if selected).
- Do not use a `Select` for this filter (chips are the contract so “filter chip selected” is a real accent surface).

### 4. Thumbnail grid

- `grid grid-cols-2 gap-4 sm:grid-cols-3 lg:grid-cols-4`.
- Each tile: `<button type="button">` wrapping a square frame `aspect-square overflow-hidden rounded-2xl border border-line bg-canvas`.
- `<img src={signedUrl} alt={…} className="h-full w-full object-cover" />`. Never `object-contain` in the grid (lightbox uses contain).
- Under the frame: description `line-clamp-2` at Body 14px / 400 / `text-ink` (or **Sem descrição.** at `text-muted` if empty); allocation meta 12px muted.
- Open tile: accent ring (reserved list). Only one lightbox at a time.
- Writer actions on the tile: icon-only **Editar imagem** (`Pencil`, `aria-label="Editar imagem"`) and **Excluir imagem** (`Trash2`, `aria-label="Excluir imagem"`) as icon buttons `min-h-11 min-w-11`. Visible on mobile always; `md`: opacity 0 until `group-hover` / `group-focus-within` (same as goals). `!canWrite`: unmount both.
- No placeholder stock photos. Empty array = empty state, not fake tiles.
- Loading signed URL: canvas well, no broken-image icon from the browser. On error: muted well + **Não foi possível mostrar a imagem.**

### 5. Lightbox (`Modal`)

- Existing `Modal` with `wide` (`max-w-3xl`). Portal already on `document.body` at `z-[100]`. Do not mount a second overlay inside AppShell overflow.
- Body: `<img>` `max-h-[70vh] w-full object-contain` + description (Body 14px) + allocation line (12px muted).
- Writer: **Editar imagem** (`Button` secondary) + **Excluir imagem** (`Button` ghost, `text-error` on the label only). Reader: no those buttons; close chrome only.
- Close: X / backdrop / Escape — existing Modal. `aria-label="Fechar"` unchanged.

### 6. Upload and edit Modals

- Default width (`max-w-lg`), not `wide`.
- Upload fields top → bottom: file trigger + helper → **Descrição** `Textarea` → **Sessão** `Select` → **Voltar** + **Adicionar imagem**.
- Hidden `<input type="file">` triggered by **Escolher arquivo** (`Button` secondary). Re-validate `file.type` and size in Zod even if `accept` is set.
- No file selected + submit → inline error on the file trigger: **Escolha um arquivo**.
- Edit: same **Descrição** + **Sessão**; no file replace this phase (out of scope).
- **Voltar** / X / Escape / backdrop: close without write; no toast.

### 7. Delete

- Existing `ConfirmDialog` `tone="danger"`. Title **Excluir imagem**. Confirm **Excluir imagem**. Cancel **Voltar** (override ConfirmDialog default — do not ship **Cancelar**).
- After confirm: service `storage.remove` then row DELETE; toast **Imagem excluída**; close lightbox if it was open.

## Interaction Contract

| Action | Behavior |
|--------|----------|
| Open `?aba=imagens` | Show `PatientImagesPanel`. Other tabs unchanged. |
| Narrow viewport, five tabs | Tablist scrolls horizontally. **Imagens** is not clipped by `overflow-hidden`. |
| Click **Adicionar imagem** | Open upload Modal. Focus **Escolher arquivo**. |
| Pick HEIC / SVG / GIF / other | Do not upload. Toast MIME copy. Stay in Modal. |
| Pick file > 8 MB | Do not upload. Toast oversize copy. Stay in Modal. |
| Submit upload with empty session | Persist as avulsa (`session_id` null). Toast **Imagem adicionada**. Close Modal. Grid refreshes. |
| Submit upload with a session | Persist tied to that `patient_sessions` id. Same toast. |
| Click thumbnail | Open lightbox. Description and allocation visible. |
| **Editar imagem** | Open edit Modal prefilled. Save → toast **Descrição atualizada**; keep new session filter membership. |
| **Excluir imagem** | ConfirmDialog (confirm **Excluir imagem**, cancel **Voltar**) → remove object + row → toast **Imagem excluída**. |
| Chip **Todas** / **Avulsas** / sessão | Filter the in-memory list. No extra fetch. |
| Session deleted in Evoluções | Image becomes avulsa (SET NULL). Gallery query invalidates with the patient. Ghost session chip disappears because `usePatientSessions` refreshes. |
| `!canWrite` | Unmount Adicionar imagem / Editar imagem / Excluir imagem. Grid + filter + lightbox remain. |
| Empresa on colleague ficha | Same as `!canWrite`. Existing consult banner. RLS is authority. |
| Hide vs disable | Never show a disabled Adicionar imagem / Editar imagem / Excluir imagem that still looks tappable (Phase 3 D-07). |
| Documentos shortcut | Unchanged **Em breve**. Not a gallery entry. |

Focus: first invalid field on upload/edit submit (`aria-invalid` + existing control error `role="alert"`). ConfirmDialog title **Excluir imagem** is the accessible name of the delete dialog. Tile icon buttons use `aria-label="Editar imagem"` and `aria-label="Excluir imagem"`. Lightbox / Modal close stays **Fechar**.

Reduced motion: inherit existing `prefers-reduced-motion` rules. Do not add enter/exit animation beyond current Modal (none). Do not animate thumbnail zoom.
