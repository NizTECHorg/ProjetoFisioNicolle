<interfaces>
Named exports, single quotes, no semicolons. Analog finance.service throwIfError + mapDbError; for Functions errors use mapGoogleCalendarError. Analog usePatientImages for dedicated hook file.

Scope string exact: https://www.googleapis.com/auth/calendar.events.owned
queryParams: { access_type: 'offline', prompt: 'consent' }
redirectTo: `${window.location.origin}/agenda`

getGoogleCalendarConnection(): Promise&lt;GoogleCalendarConnection | null&gt;
- from('google_calendar_connections').select('google_email, connected_at').maybeSingle()
- map snake → camel; mapDbError on PostgREST errors

linkGoogleCalendar(): Promise&lt;void&gt;
- linkIdentity as above; throw mapAuthError on Auth errors
- Do not add Google to LoginPage

vaultGoogleTokensIfPresent(): Promise&lt;'vaulted' | 'skipped'&gt;
- getSession(); if no provider_refresh_token return skipped
- functions.invoke('google-calendar-connect', { body: { refreshToken, accessToken: provider_token, googleEmail from user/identities if available } })
- On missing refresh after expected OAuth return, throw Error(GOOGLE_CALENDAR_COPY.vaultMissing)
- Never localStorage.setItem of tokens

exportVisibleMonth(input: { fromIso: string; toIso: string }): Promise&lt;GoogleCalendarExportResult&gt;
- exportMonthSchema.parse(input)
- invoke google-calendar-export
- Map Functions/HTTP failures through mapGoogleCalendarError; if status/code indicates reconnect throw Error with tokenExpired copy (or attach code needs_reconnect)

disconnectGoogleCalendar(): Promise&lt;void&gt;
- invoke google-calendar-disconnect
- Best-effort supabase.auth.unlinkIdentity for the google identity (Pitfall 4 — still succeed disconnect if unlink fails after secrets deleted; map PT if both fail)

Hooks (UI-SPEC toasts):
- useGoogleCalendarConnection → queryKey ['google-calendar', 'connection']
- useLinkGoogleCalendar → mutationFn linkGoogleCalendar (may redirect; toast on return via vault)
- useVaultGoogleTokens → on success vaulted toast Google conectado + invalidate connection
- useExportGoogleCalendarMonth → success/partial/empty/error toasts; on needs_reconnect invalidate + let page switch CTA
- useDisconnectGoogleCalendar → toast Google desconectado + invalidate

Do not restyle primitives. Do not call Google REST from the browser.
</interfaces>
</context>
