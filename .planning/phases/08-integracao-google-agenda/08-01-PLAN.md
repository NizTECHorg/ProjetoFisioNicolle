mapSessionToGoogleEvent return shape (plain object for Calendar REST — not a class):
- summary: `${patientName} · ${type}`
- location: omit or undefined when place is empty or '—'
- description lines allow-list only: optional Código: {patientCode}, Status: {status}, fixed Origem: agenda Fisio (exportação)
- start/end: { dateTime: ISO string, timeZone: 'America/Sao_Paulo' }
- end = start + DEFAULT_EVENT_DURATION_MS (60 * 60 * 1000)
Never include evolution SOAP, evaluation fields, or notes.

UI-SPEC copy constants (GOOGLE_CALENDAR_COPY object, Portuguese exact):
- connectCta: Conectar Google
- reconnectCta: Reconectar Google
- exportCta: Exportar mês
- disconnectCta: Desconectar Google
- stripHeading: Google Calendar
- noticeDisconnected: Esta integração só exporta sessões da Agenda para o Google. Eventos do Google não entram na Agenda da clínica.
- noticeConnected: Exportação para o Google — não é sincronização bidirecional.
- connectedAs: Conectado como (UI appends email)
- monthScopePrefix: Exporta as sessões do mês visível:
- connectSuccess: Google conectado
- disconnectSuccess: Google desconectado
- exportSuccess: Sessões exportadas para o Google
- exportPartial: Algumas sessões foram exportadas. Verifique o Google Calendar.
- exportEmpty: Nenhuma sessão neste mês para exportar.
- exportEmptyBody: Agende uma sessão na Agenda ou mude o mês visível.
- exportError: Não foi possível exportar para o Google. Tente de novo ou reconecte a conta.
- tokenExpired: Sua conexão com o Google expirou. Reconecte para continuar exportando.
- networkError: Não foi possível falar com o Google. Tente de novo em instantes.
- vaultMissing: Não foi possível guardar a conexão. Reconecte o Google e autorize novamente.
- loadConnectionFail: Não foi possível verificar a conexão com o Google. Tente de novo em instantes.
- disconnectTitle: Desconectar Google
- disconnectDescription: A exportação para o Google Calendar será desligada nesta conta. Sessões já enviadas permanecem no Google.
- disconnectConfirm: Desconectar Google
- disconnectCancel: Voltar

mapGoogleCalendarError(error: { message?: string; status?: number; code?: string | number } | null | undefined): string
- 401 / 403 / invalid_grant / insufficient / needs_reconnect → tokenExpired copy
- network / Failed to fetch / fetch failed / 5xx / unavailable → networkError copy
- empty / empty_month → exportEmpty copy
- 42501 / permission / RLS → mapDbError path (Você não tem permissão para esta ação.)
- else → exportError copy
Never return raw Google JSON or English OAuth strings.
