# Phase 8 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase goal:** Na Agenda (`/agenda`), o profissional conecta a própria conta Google e **exporta** as sessões do mês visível para o Google Calendar. Google → app está fora de escopo; a UI deixa claro que é **exportação**, não sync bidirecional.

**Sources:** CONTEXT D-01–D-09; RESEARCH export-only + export visible month + `google_email` + reconnect PT; REQ-20; tokens from `src/index.css`; chrome from `CalendarPage.tsx`; spacing / type / color reused from `07-UI-SPEC.md` (approved) and prior clinic UI-SPECs.

**Do not restyle** `Button`, `Input`, `Select`, `Modal`, `PageHeader`, `ConfirmDialog`, `DataTable`, `Badge`, `ToastViewport`, or AppShell. Do **not** add shadcn, Google GIS scripts, `googleapis` npm, or `clsx`. Do **not** add a Google button on `LoginPage`. Preserve existing Agenda calendar grid, day panel, and **Nova sessão** Modal chrome.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px (`text-sm`) | 400 | 1.5 |
| Body | 14px (`text-sm`) | 400 | 1.5 |
| Heading | 20px (`text-xl`) | 600 | 1.2 |

Display is **unused** this phase — `PageHeader` title **Agenda** already owns page display via existing `text-3xl` / `sm:text-4xl` chrome; do not invent a second display for Google.

- `PageHeader` title remains `text-3xl` / `sm:text-4xl` / `lg:text-[2.125rem]` / 600.
- Month label in calendar card remains `text-sm font-semibold`.
- Weekday headers remain `text-[11px]` uppercase muted.
- Day panel headings remain `text-sm font-semibold`.
- `Modal` title remains `text-lg` / 600.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f3f5f8` (`canvas`) | Agenda page background (existing) |
| Secondary (30%) | `#ffffff` (`surface`) + `#0b1d36` (`forest`) | Calendar cards, Google strip surface, primary **Conectar Google** / **Exportar mês**; selected day stays forest |
| Accent (10%) | `#2f7dff` (`accent`) | Reserved list below — never body text or primary buttons |
| Destructive | `#dc4a4a` (`error`) | **Desconectar Google** confirm (`ConfirmDialog` `tone="danger"`), connection/export error article, toast errors |

Accent reserved for:

1. **Export-only notice** soft well — `border-accent/30 bg-accent-soft` with `text-forest` body (same pattern as day-panel quadro due cards)
2. Connected status chip / soft pill — `bg-accent-soft text-forest` (analog to existing **Hoje** chip)
3. Focus ring on controls already in `Input` / `Select` / `Button`
4. Success toast surface (`bg-accent-soft` + `border-success/30`) — already in `ToastViewport`

Accent is **not** for: primary **Conectar Google** / **Exportar mês** (Button stays `bg-forest`), **Desconectar Google** (secondary or danger confirm only), body copy (`text-ink`), calendar selected day (stays `bg-forest`), or month chevrons.

**Focal point:** When disconnected, **Conectar Google** is the strip anchor. When connected, **Exportar mês** is the strip anchor; **Desconectar Google** is secondary. Existing **Nova sessão** in `PageHeader` stays; do not demote it or move Google CTAs into the header action slot unless both fit on `sm+` without wrapping into an unreadable cluster — prefer Google actions **inside the strip**, leave **Nova sessão** alone in `PageHeader.action`.

Do not recolor AppShell, calendar grid dots, or day-panel session cards.

### Toasts e erros

| Event | Message | Tone |
|-------|---------|------|
| Connect success | Google conectado | success |
| Disconnect success | Google desconectado | success |
| Export success (all ok) | Sessões exportadas para o Google | success |
| Export success (partial) | Algumas sessões foram exportadas. Verifique o Google Calendar. | success |
| Export empty month | Nenhuma sessão neste mês para exportar. | error *(or info toast — prefer error so it is noticed)* |
| Token / 401 / 403 | Sua conexão com o Google expirou. Reconecte para continuar exportando. | error |
| Network / Google down | Não foi possível falar com o Google. Tente de novo em instantes. | error |
| Permission / RLS | `mapDbError` / `mapGoogleCalendarError` — existing “Você não tem permissão para esta ação.” when applicable | error |
| Missing refresh after OAuth | Não foi possível guardar a conexão. Reconecte o Google e autorize novamente. | error |
| Load connection fail | Não foi possível verificar a conexão com o Google. Tente de novo em instantes. | in-page strip article, not a second toast |

Reconnect path: on 401/403 toast (or strip error), show / emphasize **Reconectar Google** as the primary strip CTA (same action as **Conectar Google** / `linkIdentity` with consent). Do not leave the user with only a toast and no button.

Do not toast English OAuth text (`access_denied`, `invalid_grant`) or SQL.

## Screens

### 1. `CalendarPage` — Google strip placement

- Mount a full-width strip **below** `PageHeader`, **above** the existing two-column calendar grid.
- Strip container: `rounded-2xl border border-line bg-surface p-4 sm:p-5` (match `dash-card` language; may reuse `dash-in` with a short delay).
- Layout: heading + export-only notice on the left; actions stacked on narrow viewports (`flex-col gap-3`), row on `sm+` (`sm:flex-row sm:items-center sm:justify-between`).
- Do **not** put Google CTAs in `PageHeader.action` (keeps **Nova sessão** as the clinical create action).
- Do **not** add Google controls inside the month grid card or the day detail card.

### 2. Disconnected state

- Show strip heading + export-only notice + **Conectar Google** (`Button` primary).
- Unmount **Exportar mês** and **Desconectar Google** (hide-write analog — do not show disabled export).
- Click **Conectar Google** → `linkIdentity` redirect flow; return to `/agenda`.

### 3. Connected state

- Show **Conectado como {google_email}** at 12px muted under the heading (or inline).
- Show export-only notice (shorter connected variant above).
- Show month scope line using the same `monthLabel` as the calendar cursor.
- **Exportar mês** primary; **Desconectar Google** secondary.
- Export targets sessions already loaded for the visible month via `useCalendarSessions` / `listSessionsInRange` — no parallel “select sessions” UI this phase (RESEARCH discretion: export visible month).

### 4. Reconnect / token-expired state

- Treat as connected metadata missing/invalid OR last export returned 401/403.
- Strip shows error article: soft `border-error/20 bg-error/5` + Body copy from toast/error table.
- Primary CTA becomes **Reconectar Google** (same handler as connect). Hide **Exportar mês** until connection is healthy again (unmount, do not disable).

### 5. Disconnect

- **Desconectar Google** opens `ConfirmDialog` `tone="danger"` with copy above.
- On confirm: disconnect mutation; toast **Google desconectado**; strip returns to disconnected state.
- Cancel / X / Escape / backdrop: close without disconnect; cancel label **Voltar**.

### 6. Existing Agenda chrome (out of restyle scope)

- Month grid, day panel, quadro dues, **Nova sessão** Modal, status Confirmar / Marcar realizada — **unchanged** visually and in copy.
- Empty day **Nada neste dia** / **Agendar sessão neste dia** remain as-is (day empty ≠ export empty).

## Interaction Contract

| Action | Behavior |
|--------|----------|
| Open `/agenda` | Load connection status; show strip disconnected or connected. Calendar grid unchanged. |
| Click **Conectar Google** / **Reconectar Google** | Start `linkIdentity` Google OAuth with Calendar scopes; `redirectTo` `/agenda`. |
| Return from OAuth with tokens | Vault via Edge Function; show connected strip with `google_email`; toast **Google conectado**. |
| Click **Exportar mês** | Export sessions in the visible month cursor range; Button `isLoading` → Aguarde.... |
| Export success | Toast **Sessões exportadas para o Google**. Stay on page; do not navigate. |
| Export empty month | Do not call Google with empty payload as success; toast empty-month copy. |
| Export 401/403 | Toast reconnect copy; switch strip to reconnect state; unmount **Exportar mês**. |
| Click **Desconectar Google** | ConfirmDialog → disconnect → disconnected strip. |
| Change month (chevrons) | Month scope label updates; export still means the new visible month. No auto-export. |
| **Nova sessão** | Unchanged Modal flow. New sessions appear in month list; user must export again to push them. |
| Hide vs disable | Never show disabled **Exportar mês** / **Conectar Google** that still looks tappable. Unmount when unavailable. |
| Login page | No Google button. Email/password only. |
| Empresa viewer | May see Agenda sessions they can SELECT; export uses caller’s Google (per RESEARCH). Same strip UI — no second consult-only banner for Google unless product later restricts export. |

Focus: after open ConfirmDialog, confirm button is reachable; Modal/Confirm close stays **Fechar** / Escape / backdrop. Export button shows existing Button loading chrome (**Aguarde...**).

Reduced motion: inherit existing `prefers-reduced-motion` / `dash-in` rules. Do not add Google logo bounce or confetti.
