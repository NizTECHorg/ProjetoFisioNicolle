listActivePrices(): select autonomo_prices where archived_at is null, order created_at, map to AutonomoPrice. Number(amount_brl).

createPrice(input: CreatePriceInput): insert owner_id from requireUserId, name sanitizeText(name, 80), amount_brl. Do not send archived_at.

updatePrice(id, input: UpdatePriceInput): update name + amount_brl for that id. This is D-04 future-only because the DB snapshot trigger/columns do not cascade — do not also update autonomo_session_charges.

archivePrice(id): update { archived_at: new Date().toISOString() }. Never call .delete() (D-03).

fetchFinanceTotals(): supabase.rpc('autonomo_finance_totals') maybeSingle, map month_total/year_total/always_total through Number to FinanceTotals. If rpc returns an array, take the first row. Do not compute totals in JS from a session list (D-09, Pitfall 2).

fetchChargeBySessionId(sessionId): autonomo_session_charges maybeSingle eq session_id. Return SessionCharge | null.

upsertSessionCharge(input: UpsertSessionChargeInput): requireUserId as owner_id. If priceId is set, insert/upsert session_id unique with price_id, is_paid; omit a client amount. On INSERT the 05-02 trigger copies catalog name/amount (T-05-03). On conflict UPDATE with the same price_id, do not depend on recopy — preserve-not-recopy: the trigger must leave amount_brl and price_name as OLD (D-04, D-07). If priceId is null, send amount_brl from adHocAmountBrl and let the trigger set price_name to Avulso. Use upsert on session_id conflict. Do not write a zero row when both priceId and adHocAmountBrl are null — return without insert (D-10 optional allocation).

markChargePaid(sessionId): update is_paid true where session_id. Do not change amount_brl. The 05-02 trigger must leave amount_brl and price_name unchanged on this UPDATE (same price_id; preserve-not-recopy).

listFinanceRealizadas(): select from patient_sessions columns id, patient_id, scheduled_at, status, created_by plus embed patients(full_name) only (calendar.service analog). Filter status eq realizada and created_by eq requireUserId(). Order scheduled_at descending. Do not embed autonomo_session_charges on this query. Then select charges where session_id in those ids (or skip the second query if no rows). Map FinanceRealizadaRow with charge null when missing. Empty array when none — no fake rows (D-10 / LGPD).

Do not import sessions.service. Do not touch patient_sessions writes except the realizadas SELECT. Do not add money to calendar.service.ts.
