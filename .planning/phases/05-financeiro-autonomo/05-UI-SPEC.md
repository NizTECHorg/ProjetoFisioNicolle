# Phase 5 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase goal:** Só o autônomo vê Financeiro. Catálogo de preços (nome + R$), alocação na sessão (catálogo XOR avulso + Pago), snapshot, e arrecadação mês / ano / sempre. Empresa e fisioterapeuta não veem a aba, não acessam `/financeiro` e não ganham campos de dinheiro na sessão.

**Sources:** tokens from `src/index.css`; chrome from `PageHeader`, `Button`, `Input`, `Select`, `Modal`, `ConfirmDialog`, `DataTable`, `Badge`, `ToastViewport`; analog screens `TeamPage` (gate + drawer-only) and `PatientSessionEditorForm` (allocation surface); product from `05-CONTEXT.md` (D-01–D-10) and `05-RESEARCH.md`; spacing / type / color reused from `03-UI-SPEC.md` (approved) and `04-UI-SPEC.md`. CONTEXT overrides ROADMAP “dois valores fixos residência vs escritório”.

**Do not restyle** `Button`, `Input`, `Select`, `Modal`, `PageHeader`, `ConfirmDialog`, `DataTable`, `Badge`, `ToastViewport`, or AppShell. Do **not** reuse `src/pages/FinancePage.tsx`, `canManageFinance`, or bakery caramel/dark chrome.

## Spacing Scale

Declared values (must be multiples of 4) — identical to Phase 3 / Phase 4:

| sm | 8px | Label-to-control gap (`space-y-2` on Input/Select); header CTA cluster |

- Do not change dashboard metric card gaps. Do not copy bakery `FinancePage` spacing.
- Native Pago checkbox: 16×16 visual, wrapped in a label with **min-h-11** so the tap target is 44px tall.

## Typography

Exactly four sizes and two weights for **new** copy in this phase (same contract as Phase 3 / Phase 4):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px (`text-sm`) | 400 | 1.5 |
| Body | 14px (`text-sm`) | 400 | 1.5 |
| Heading | 20px (`text-xl`) | 600 | 1.2 |
| Display | 30px (`text-3xl`) | 600 | 1.2 |

Hints, inline errors, `Badge` text, muted list meta, and toast dismiss stay at **12px** (`text-xs`) because `Input`/`Select`/`Badge`/`ToastViewport` already render that size — do not invent a fifth size; do not change those components.

Existing chrome exceptions (do not restyle):

- `PageHeader` title remains `text-3xl` / `sm:text-4xl` / `lg:text-[2.125rem]` at weight 600. `/financeiro` title is **Financeiro**.
- `Modal` title remains `text-lg` / 600.
- `Input`/`Select` labels remain `text-sm font-medium` (500) inside those components.
- Header / primary `Button` labels stay 14px / 600 (existing `Button` chrome).
- Dashboard metric numbers stay `text-5xl` / `lg:text-4xl` — out of scope; **do not** reuse that size on finance totals. Totals use **Display 30px / 600**.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f3f5f8` (`canvas`) | `/financeiro` page background; Modal backdrop stays `bg-forest/40` |
| Secondary (30%) | `#ffffff` (`surface`) + `#0b1d36` (`forest`) | Total cards, catalog table, realizadas list, primary **Novo preço**, sidebar/nav stays forest |
| Accent (10%) | `#2f7dff` (`accent`) | Reserved list below — never body text or primary buttons |
| Destructive | `#dc4a4a` (`error`) | **Arquivar preço** confirm, inline/server errors, load-error article |

Accent reserved for:

1. Focus ring on `Input`/`Select` (`focus:border-accent` + `focus:ring-accent/25`) — already in those components
2. Empty-state icon wells on `/financeiro` (`bg-accent-soft` / `text-accent`) — catalog empty and realizadas empty
3. Badge **Pago** (`Badge` tone `success` — `bg-accent-soft` + `text-success`)
4. Success toast surface (`bg-accent-soft` + `border-success/30`) — already in `ToastViewport`

Accent is **not** for: primary `Button` (stays `bg-forest`), page title, body copy, totals numbers (`text-ink`), **Arquivar** (ghost + `text-error` on the label only), Pago checkbox (`accent-forest`), sidebar active item (stays `bg-white/10`), or any bakery caramel class.

**Focal point:** **Novo preço** is the visual anchor on `/financeiro` — `Button` primary in the `PageHeader` action slot. The three total cards are supporting chrome: surface cards, Display amount in ink, no accent wash, no `text-5xl`. Do not enlarge totals to compete with the CTA.

Do not recolor AppShell, dashboard stat cards, or `PatientSessionEditorForm` clinical fields. Empresa/fisio session forms stay exactly as they are (no money chrome).

## Screens

### 1. Navegação — Financeiro no drawer

- Add `{ label: 'Financeiro', path: '/financeiro', icon: Wallet }` to `navigationItems`.
- `clinicNavigationItems`: show `/financeiro` only when `accountType === 'autonomo'`; keep `/equipe` empresa-only.
- Do **not** add Financeiro to `mobileNavItems`. Assert length **4**.
- Mobile reaches Financeiro via the hamburger drawer (same as Equipe).
- Do not add Financeiro chrome to the dashboard header.

### 2. `/financeiro` — `AutonomoFinancePage`

- Inside `AppShell`. `section.mx-auto.w-full.max-w-7xl` + `PageHeader` (same as `TeamPage` / `PatientsPage`).
- Gate: `if (!canSeeFinance(profile?.accountType)) return <Navigate to="/pacientes" replace />`.
- Loading: forest-border spinner in `min-h-48` surface (clone TeamPage).
- Error: `article` `rounded-2xl border border-error/20 bg-error/5 px-6 py-8 text-sm text-error` with the error copy.
- Body order (top → bottom), `space-y-6`:
  1. **Totais** — three cards
  2. **Catálogo de preços**
  3. **Sessões realizadas**
- `PageHeader` `action`: **Novo preço** (`Button` primary, `<Plus size={16} />`). Visible whenever the page is showing (including empty catalog). Do not hide or disable it on empty/error of the list; empty/error belongs in the sections.

### 3. Totais

- Grid: `grid gap-4 sm:grid-cols-3`.
- Each card: `rounded-2xl border border-line bg-surface p-4 md:p-6`.
- Label: 14px / 400 / `text-muted`.
- Amount: 30px / 600 / `text-ink` / `leading-tight`. Always `formatCurrency`.
- Hint under the grid: 12px muted, the prepaid sentence.
- Zero is a valid total (`R$ 0,00`). Do not swap the row for an empty-state well.

### 4. Catálogo

- Section heading 20px / 600.
- Loading/error follow TeamPage geometry.
- Empty: card `flex min-h-40 flex-col items-center … rounded-2xl border border-line bg-surface px-6 py-10 text-center`; icon well 48×48 `rounded-2xl bg-accent-soft text-accent` with `Wallet` 22px; heading 14px/600; body 14px/400 muted (12px is allowed for the supporting sentence if matching Equipe empty — Equipe uses `text-xs` for empty body; **this phase uses 14px body** for the next-step sentence so it meets “empty + next step” at Body size. Keep Equipe `text-xs` only on DataTable empty, which the component already renders).
- For DataTable empty (realizadas): the kit already uses `text-sm` heading + `text-xs` description — do not fork DataTable.
- Non-empty catalog: `DataTable` columns Nome (14px/600), Valor (`formatCurrency`), Ações.
- Ações: **Editar preço** (`Button` ghost) + **Arquivar** (`Button` ghost, `text-error` on the label only). Hit area ≥ 44px.
- **Arquivar** opens `ConfirmDialog` `tone="danger"` with the archive copy. Edit does **not** confirm.
- Create and edit use existing `Modal` (default width, already portals to `document.body`). Amount `Input` is `type="text"` `inputMode="decimal"` `autoComplete="off"` — never `type="number"`.
- Duplicate names allowed. No uniqueness error.

### 5. Sessões realizadas

- Section heading 20px / 600.
- Query: `status = 'realizada'` owned by the autônomo. Do **not** list agendada here (prepaid still counts in totals).
- Desktop: `DataTable`. Mobile: stacked cards `rounded-2xl border border-line bg-surface p-4` (clone Equipe pending), each with patient name 14px/600, date 12px muted, preço/valor, badge, action.
- Date via `formatDate` / `formatDateTime` from `@/lib/security`.
- **Completar valor** opens `Modal` (not `wide`) with the same XOR + Pago fields as the session block. Submit **Salvar valor**.
- **Marcar como pago** is immediate (no dialog), like Equipe Aceitar. Requires an existing charge. Toast on success.
- Paid rows: Badge only.

### 6. Bloco financeiro na sessão

- Mount inside `PatientSessionEditorForm` only when `canSeeFinance(profile.accountType)`.
- Placement: after the Local/Tipo grid, **before** the realizada clinical textareas / the Agendar helper paragraph. Visible in both modes.
- Layout: heading 14px/600 “Valor da consulta”; then `grid gap-4 sm:grid-cols-2` for Select + avulso; then Pago label; then optional snapshot line (edit).
- XOR interaction:
  1. Choosing a catalog price clears avulso.
  2. Typing in avulso sets catalog Select to `""` (Sem valor).
  3. Both filled → Zod error on avulso (copy above). Neither filled → valid (allocation optional).
  4. Checking Pago with neither → Zod error “Informe um valor para marcar como pago.”
- Empty active catalog: unmount Select; show avulso + empty-catalog hint. Avulso remains usable.
- Archived prices never appear in the Select. Existing snapshot still shows on the **Valor gravado** line.
- Pago: native `<input type="checkbox" className="accent-forest" />` inside a `label` `flex items-center gap-2 text-sm text-ink` `min-h-11`. Default `false`. Do not copy bakery `accent-caramel`.
- `place` stays the clinical Local `Input`. No residência/escritório enum.
- Dashboard shortcut already mounts this form — finance fields appear there automatically for autonomo. Do not add a parallel widget.
- `CalendarPage` create stays without money this phase. Do not invent a third XOR control there.

### 7. Overlays / portal

- Catalog create, catalog edit, Completar valor, and archive `ConfirmDialog` all use existing `Modal`.
- `Modal` already `createPortal(..., document.body)` at `z-[100]`. Do not mount a second overlay inside AppShell overflow. Close X keeps `aria-label="Fechar"`.
- If any new overlay is added, it **must** portal to `document.body` (Phase 4 fix).

## Interaction Contract

| Action | Behavior |
|--------|----------|
| Autônomo opens drawer | Sees Financeiro (`Wallet`) after the four clinic items (Equipe hidden). |
| Empresa / fisio drawer | No Financeiro item. |
| Empresa / fisio visits `/financeiro` | Silent redirect `/pacientes`. No toast. |
| Click **Novo preço** | Open create Modal. Focus Nome do preço. |
| **Cadastrar preço** success | Close Modal; toast **Preço cadastrado**; catalog query refreshes. |
| **Editar preço** | Open edit Modal prefilled; hint about future-only. Save → toast; snapshots unchanged. |
| **Arquivar** | ConfirmDialog → archive UPDATE → row leaves the table and the session Select; toast. |
| **Voltar** / X / Escape / backdrop on catalog Modal | Close without write; no toast. |
| Select catalog price on session | Clear avulso. |
| Type avulso on session | Clear catalog Select. |
| Check Pago with no amount | Client error; do not submit. |
| Save sessão with XOR + Pago | Persist charge snapshot; invalidate `['finance']` and patient sessions. |
| **Completar valor** | Modal XOR + Pago; **Salvar valor** upserts charge. |
| **Marcar como pago** | Immediate; requires existing amount. |
| Hide vs disable | Hide finance fields and row actions the viewer must not use. Do not show disabled Pago / Novo preço / Marcar como pago that still look tappable (Phase 3 D-07). `canSeeFinance` is UX only; RLS is authority. |
| Calendar Nova sessão | No money fields this phase. Allocate later from ficha, dashboard shortcut, or `/financeiro` list. |

Focus: first invalid field on submit (`aria-invalid` + existing Input error `role="alert"`). ConfirmDialog title is the accessible name of Arquivar preço.

Reduced motion: inherit existing `prefers-reduced-motion` rules. Do not add enter/exit animation beyond current Modal (none). `/financeiro` header/cards may keep `dash-in` like Equipe.
