# Phase 18 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase goal:** No rodapé da barra lateral, ao lado de Sair, um botão só com ícone abre a página da própria conta. Lá a pessoa troca a foto, o nome e a senha. A senha nova só grava depois de conferir a senha atual.

**Sources:** D-01–D-05 and the phase boundary in `18-CONTEXT.md`; route `/conta`, footer `NavLink`, `AccountPage` (not `SettingsPage`), and password copy in `18-RESEARCH.md`; REQ-29 in `REQUIREMENTS.md`; tokens in `src/index.css`; footer chrome in `AppShell.tsx`; form chrome in `Input`, `Button`, `PageHeader`, `ConfirmDialog`, `ToastViewport`; photo overlay pattern from `16-UI-SPEC.md` (approved). Spacing, type, and color reused from `05-UI-SPEC.md` and `16-UI-SPEC.md`.

**Do not restyle** `Button`, `Input`, `PageHeader`, `Modal`, `ConfirmDialog`, `ToastViewport`, `Badge`, or the forest sidebar. Do **not** route or restyle `SettingsPage`. Do **not** add shadcn, a crop modal, a camera capture sheet, an e-mail editor, account deletion, or an “esqueci a senha” / OTP path.

| md | 16px | Card padding on viewports below `md` (`p-4`); gap between the photo block and the name field (`gap-4`) |

- **Remover foto** is a text control with minimum hit area **44×44px** (`min-h-11`, `px-2`). It sits beside the circle, not as a second hotspot on top of it.

| Body | 14px (`text-sm`) | 400 | 1.5 |

Read-only values (e-mail, tipo de conta) are Body. Card titles (**Foto e nome**, **Senha**) are Heading. The page title is Display via the existing `PageHeader`.

- `Input` labels remain `text-sm font-medium` (500) inside that component. Do not add a third weight on new elements outside `Input`.
- `Button` labels stay 14px / 600.
- `ConfirmDialog` title stays the existing Modal `text-lg` / 600.
- Footer name stays `text-sm font-medium text-white`. Footer account-type line stays `text-xs text-white/45`. Initials in the footer circle stay `text-xs font-semibold`.

## Copywriting Contract

All user-facing strings in Portuguese (pt-BR). No Submit, OK, Save, or Cancel on new chrome. No English, SQL, MIME enums, bucket names, or byte counts in toasts.

| Element | Copy |
|---------|------|
| Primary CTA | **Salvar nome** on the identity card. **Salvar senha** on the password card. The footer control has no visible label; its accessible name is **Minha conta**. |
| Empty state heading | Sem título de página vazia. A rota só abre com sessão. Sem foto, o círculo mostra as iniciais. |
| Empty state body | Sem frase “Sem foto” ou “Nenhuma foto”. Os três campos de senha começam vazios. |
| Error state | Senha atual incorreta. A senha não foi alterada. |
| Destructive confirmation | Remover foto: “A foto sai da sua conta. As iniciais voltam.” Confirm: **Remover foto**. Cancel: **Voltar**. |

### Entrada (D-01, D-02)

The footer control is a `NavLink` to `/conta` in the same strip as Sair, immediately before that button. Visible content is only `CircleUser` (`size={17}`, `aria-hidden`). No visible word “Minha conta”.

| Attribute | Value |
|-----------|-------|
| Accessible name | Minha conta |
| `title` | Minha conta |
| Idle | `text-white/40` |
| Hover / active route | `bg-white/10 text-white` |
| Hit area | `min-h-11 min-w-11`, `rounded-xl`, centered icon |

Clicking it navigates to `/conta` and closes the mobile drawer (`setIsMenuOpen(false)`), the same way other drawer links do. It does not open a file picker and does not sign out.

Do not add the item to the bottom bar. Do not add a visible label in the drawer list.

### Página

`PageHeader` title **Minha conta**. Description: **Foto, nome e senha desta conta.**

Two stacked cards. Each card: `rounded-2xl border border-line bg-surface p-4 md:p-6`.

**Card Foto e nome**

- Heading: **Foto e nome**
- Circle 64×64 (`h-16 w-16`), `rounded-full`, `overflow-hidden`.
- With a photo: `<img alt="" className="h-full w-full object-cover" />`. Broken image falls back to initials. No toast.
- Without a photo: initials on `bg-accent/20 text-accent`, same two-letter rule as the footer (`displayName` split, first two words, uppercased). No “Sem foto” caption.
- The circle is a `<label>` with a visually hidden file input. Overlay matches the patient photo scrim: `bg-forest/55`, white `Camera` `aria-hidden` at 20px, visible on hover, on focus-within, and always when `(hover: none)`. The icon does not capture the click.
- Accessible name of the file input: **Escolher foto** when there is no photo, **Trocar foto** when a photo is showing.
- File input: `accept="image/png,image/jpeg,image/webp,.png,.jpg,.jpeg,.webp"`, `className="sr-only"`. No `capture`. No `multiple`. After `change`, set `input.value = ''`.
- While the upload is pending: `aria-busy="true"` on the label, ignore further changes, replace the camera with the existing white spinner (`h-4 w-4 animate-spin rounded-full border-2 border-white border-t-transparent`).
- **Remover foto** renders only when a photo is already saved. Classes: `inline-flex min-h-11 items-center px-2 text-xs text-muted hover:text-error`. It opens `ConfirmDialog` and does not open the file picker. Unmount it when there is no photo.
- Read-only **E-mail**: the signed-in address as text, not an input, not a link. Hint under it: **O e-mail de login não muda aqui.**
- Read-only **Tipo de conta**: `accountTypeLabel` (Autônomo, Empresa, or Fisioterapeuta). Not a select. Not `profiles.role`.
- Name field: existing `Input`, label **Nome**, prefilled with the current display name. `autoComplete="name"`.
- Submit of this card is **Salvar nome** only. This form has no password fields.
- **Salvar nome** is disabled when the trimmed value equals the saved name, and while the save is pending (`Button` `isLoading`, label stays the component’s **Aguarde...**).

**Card Senha**

- Heading: **Senha**
- Supporting line (Body, `text-muted`): **Informe a senha atual para gravar a nova.**
- Three `Input` fields, `type="password"`, placeholder `••••••••••••`, in this order:
  1. **Senha atual** — `autoComplete="current-password"`
  2. **Nova senha** — `autoComplete="new-password"`, hint **Mínimo 8 caracteres, com maiúscula, minúscula, número e caractere especial**
  3. **Confirmar nova senha** — `autoComplete="new-password"`
- Text toggle under the fields, same pattern as the cadastro: **Mostrar senhas** / **Ocultar senhas**. It reveals all three fields together. It does not submit.
- Submit is **Salvar senha**. This form does not send the name or the photo.
- **Confirmar nova senha** is client-only. The request sends the new password and the current password together. It never sends the new password alone.

### Verificação da senha (D-05 / REQ-29.4)

The password card always asks for the current password before a new one can be saved. Do not design a one-field “nova senha” form, a “esqueci a senha” link, an e-mail code, or a `reauthenticate` step.

| Situation | What the person sees | What must not happen |
|-----------|----------------------|----------------------|
| **Senha atual** empty on submit | Inline error **Informe a senha atual.** | No password request. The saved password stays. |
| **Nova senha** empty on submit | Inline error **Informe a nova senha.** | No password request. |
| **Confirmar nova senha** empty | Inline error **Confirme a nova senha.** | No password request. |
| Confirmation does not match | Inline error **As senhas não coincidem.** on **Confirmar nova senha** | No password request. |
| New password fails the existing `passwordSchema` | The schema message already used at cadastro (mínimo, máximo, minúscula, maiúscula, número, caractere especial, e-mail na senha) | No password request. Do not show **A senha não atende aos requisitos de segurança.** for these cases; show the specific schema line. |
| Current password is wrong | Inline error on **Senha atual**: **Senha atual incorreta.** The error state sentence may also appear as that field’s description. No success toast. | The password is not changed. Do not sign out. Clear only **Senha atual** and move focus to it. Keep **Nova senha** and **Confirmar nova senha**. |
| New password equals the current one | **A nova senha deve ser diferente da atual.** | The password is not changed. |
| Save succeeds | Toast **Senha atualizada.** Clear all three fields. Stay on `/conta`. | Do not sign out. Do not navigate to login. The current session remains. |
| Too many attempts | Toast **Muitas tentativas. Aguarde e tente novamente mais tarde.** | Do not change the password. |
| Network / other failure | Toast **Não foi possível atualizar a senha. Tente de novo.** | Do not change the password. Do not start an e-mail reset. |

Map `current_password_invalid` and `current_password_required` to **Senha atual incorreta.** before any generic branch that treats the word “password” as a weak-password error. A wrong current password must not be described as a weak new password.

### Toasts e erros da foto e do nome

| Event | Message | Tone |
|-------|---------|------|
| Name saved | Nome atualizado. | success |
| Name save failed | Não foi possível salvar o nome. Tente de novo. | error |
| Name shorter than 2 characters | Nome deve ter pelo menos 2 caracteres | inline on **Nome** |
| Name longer than 100 characters | Nome muito longo | inline on **Nome** |
| Name has characters outside the cadastro regex | Nome contém caracteres inválidos | inline on **Nome** |
| Photo saved | Foto atualizada. | success |
| Photo removed | Foto removida. | success |
| Not PNG, JPEG, or WebP (including HEIC, GIF, PDF, SVG) | Envie PNG, JPEG ou WebP. | error |
| Original file over 8 MB, before decode | A foto deve ter no máximo 8 MB. | error |
| Decode, crop, or save failure | Não foi possível salvar a foto. Tente de novo. | error |
| Remove failure | Não foi possível remover a foto. Tente de novo. | error |
| RLS / no permission | Você não tem permissão para esta ação. | error |
| Picker dismissed with no file | No toast | — |

After a successful name or photo save, the footer name and the footer circle update in the same session, without a new login. A missing photo in the footer keeps the current initials well (`bg-accent/20 text-accent`). The footer circle is display-only: it is not a file input.

### Fora desta página

Do not add controls for troca de e-mail, exclusão de conta, convite de equipe, or foto de paciente. **Sair** stays the existing footer button. Do not put **Encerrar sessão** on `/conta`.
